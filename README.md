# Student Grade Manager

This is a simple Python program I made to practice the basics of Python programming.

The program asks for a student's name and their scores in Math, Python, and English. It then calculates the average and checks if the student passed based on a passing score of 75.

## What the Program Does

- Asks for the student's name
- Gets scores for Math, Python, and English
- Calculates the average score
- Checks if the student passed
- Displays the student's results

## Example

```text
===== STUDENT GRADE MANAGER =====

Enter your name: John
Enter your Math score: 85
Enter your Python score: 90
Enter your English score: 88

===== STUDENT RESULTS =====
Student name: John
Math score: 85.0
Python score: 90.0
English score: 88.0
Average: 87.67
Passing score: 75
Did the student pass? True
